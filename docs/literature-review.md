# SBOMGuard Literature Review

## Project
SBOMGuard: Automated Framework for SBOM Generation, Vulnerability Analysis, and Supply Chain Risk Assessment

## Domain
Cybersecurity and Software Supply Chain Security

## Literature Review

### 1. An Empirical Study on Software Bill of Materials: Where We Stand and the Road Ahead
This study examines the current practices and challenges surrounding SBOM adoption in software development. It investigates how practitioners generate, distribute, validate, consume, and maintain SBOMs. The study uses interviews and survey responses to understand practical experiences with SBOMs and identifies issues related to tooling, standards, quality, and security.

### 2. On the Way to SBOMs: Investigating Design Issues and Solutions in Practice
This research investigates practical design and implementation issues associated with SBOMs. It examines discussions from real software-development environments to identify problems encountered throughout the SBOM lifecycle and the solutions proposed by developers and practitioners.

### 3. SBOM Generation Tools in the Python Ecosystem: an In-Detail Analysis
This paper provides a detailed analysis of SBOM generation tools used in the Python ecosystem. It examines package managers, metadata collection, direct and transitive dependencies, and the reasons why generated SBOMs may become incomplete or inconsistent.

### 4. On the Security Blind Spots of Software Composition Analysis Caused by Cloning and Shading
This study examines security blind spots that occur when vulnerable software components are cloned, copied, repackaged, or shaded. It shows that traditional software composition analysis may fail to identify vulnerable code when its original package identity has been changed.

### 5. Hidden Dependencies and Component Variants in SBOM-Based Software Composition Analysis
This research studies hidden code-level dependencies and component variants that may not be adequately represented in conventional SBOMs. It evaluates the impact of these issues on vulnerability analysis and examines how component lineage and additional metadata can improve analysis.

### 6. Risk-Aware Software Supply Chain Security For Aviation Systems Using SBOM
This research proposes an SBOM-driven approach for software supply-chain security in aviation systems. It combines SBOM information, vulnerability intelligence, and policy-based deployment controls within a multi-cloud DevSecOps environment.

### 7. An Intelligent SBOM-Driven Framework for Adaptive Vulnerability Risk Scoring in Cloud Supply-Chain Security
This paper presents an SBOM-based vulnerability risk-scoring approach that uses vulnerability severity information to prioritize findings. The framework integrates SBOM generation and vulnerability scanning and provides a normalized risk score for software components.

### 8. AI-Driven SBOM: Automated Software Bill of Materials Generation and Management
This research proposes an AI-based approach for automated SBOM generation and management. It combines multiple AI techniques to identify software components from different input sources and produce standardized SBOM representations.

### 9. Supply Chain Risk Analysis via SBOM Data Enrichment
This study explores the enrichment of SBOM data with external repository and package information. It uses metadata such as repository activity, contributors, commits, and maintenance characteristics to identify additional software supply-chain risks.
